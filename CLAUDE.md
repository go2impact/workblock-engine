## What This Is

A pure calculation library that transforms raw activity and keystroke telemetry into workblocks (temporal work sessions) and atomic slices (smallest meaningful units of work). Extracted from productivity-insights. No I/O — DataFrames in, DataFrames out. Only dependency is Polars.

## Commands

```bash
uv sync --group dev      # Install dev dependencies
uv run pytest            # Run all tests
uv run pytest tests/test_cleaning.py -v              # Run a single test file
uv run pytest tests/test_engine.py::test_name -v     # Run a single test
uv run pytest --cov=workblock_engine                 # Run with coverage
uv run pytest tests/test_equivalence.py -v           # Equivalence tests against golden files
```

## Architecture

**Public API:** `from workblock_engine import process` — single entry point returning `WorkblockResult(workblocks, atomic_slices, skipped_users)`.

**Pipeline stages** (each user processed independently, failures isolated via `skipped_users`):

1. **Cleaning** (`cleaning/`) — Normalize columns, deduplicate, extract app names, compress keystrokes. `ActivityCleaner` and `KeystrokeCleaner` are separate classes.
2. **Overlap resolution** (`building/overlap.py`) — Trim earlier activity's end time when activities overlap (later-starting wins).
3. **Keystroke matching** (`matching/`) — 4-phase algorithm ensuring 100% match rate: exact match → nearest neighbor → gap filling → orphan capture. Phases 3-4 create synthetic activities (`matching/synthetic.py`).
4. **Workblock building** (`building/workblock_builder.py`) — Group by 60-min gaps, split at midnight, decompose into minute-level atomic slices with keystroke affinity voting for primary app selection.
5. **Output assembly** (`engine.py`) — Schema enforcement, type casting, metadata injection. Schemas defined as `WORKBLOCK_SCHEMA` and `SLICE_SCHEMA` dicts in `engine.py`.

**Key design constraints:**
- Pure functions only — no file I/O, no env vars, no network calls
- All timestamps are UTC
- Workblock IDs are deterministic: `wb:<user_hash>:<time_hash>:<seq>` (MD5 + base62)
- Every keystroke must be assigned to an activity (synthetic if needed) — never silently dropped

## Equivalence Testing

`tests/test_equivalence.py` compares output against golden files generated by the productivity-insights repo. Known intentional differences (exec format, provenance fields, raw_keystrokes format) are excluded from comparison. To regenerate goldens, run `generate_equivalence_golden.py` from the productivity-insights repo.
